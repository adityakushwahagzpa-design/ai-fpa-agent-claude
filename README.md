# AI-Powered FP&A Agent using Claude

Claude set up as an FP&A assistant and tested on **24 months of budget vs actual data** for a synthetic retail company (revenue, gross profit, EBITDA).

## What was done
- Excel dataset with a SUMIFS-based P&L summary
- Custom instructions so Claude produces variance analysis, risk flags, 3-month forecasts and management commentary

## Results
- In the December 2025 review, the agent caught **all 3 planted anomalies**: a June 2024 COGS spike, Nov–Dec 2025 marketing overspend and a December revenue shortfall
- It traced the **₹47.3 lakh EBITDA miss** to the revenue shortfall (62%) and marketing overspend (36%)

## Tools
Claude · Prompt Engineering · Excel
